邮件收货助手 · WINDOWS DESKTOP APP · 高保真设计图

客户发来的图稿，
自己落进该去的文件夹。

MailHarbor 常驻在一台不关机的 Windows 电脑上，通过 IMAP 盯着工厂邮箱（回信用 SMTP）：客户邮件的标题里写着 「原图+手机壳 / 原图+卡套 / 原图+浴室垫」，软件识别到关键词后，把 ZIP、TIF 附件自动复制到 该品类对应的一个或多个本地文件夹，并回信告诉客户「已收到」。

01

它每天替你做什么

整条链路只有一件事需要人来做：在规则页把新的品类关键词和它该去的文件夹加上。其余全自动。

01 / 收

盯信箱

IMAP 待命、有新信即时发现，掉线自动重连补扫，不占带宽、不占人手。

02 / 认

认关键词

标题命中「原图+卡套」→ 这条单归卡套；没命中就跳过，不误存。

03 / 落

多路径落盘

同一份附件复制到该品类配置的每个文件夹（生产 + 备份）。

04 / 回

回信确认

全部必达路径成功后，自动回一封「已收到，共 N 个文件」。

05 / 记

留痕可查

谁、什么时候、命中哪条规则、存到哪几个路径，全部可查可重试。

02

视觉语言：纸与墨

客户的行业是印刷定制，软件就该长得像车间里那张工单，而不是又一个通用后台。 暖米白是未涂布的纸，深墨蓝是印上去的字，朱红只用来标「这一条要人看一眼」。 中文排版是主角：标题宋体、正文苹方、数字全用等宽对齐。

03

高保真设计图

设计基准 1440×900。以下按软件左侧导航从「概览」到「记录」排列，第 03 屏是整套设计的核心。

01

概览 · 今天有没有在干活

每日第一眼

操作员每天上班只看这一屏：软件在不在跑、邮箱通不通、今天收了多少件、哪些盘快满了、最近收到的是什么。所有异常都从这里点进去。

02

邮箱账户 · 换号不用找我们

SMTP / IMAP

客户明确要求：用 SMTP，不要授权。所以账户页是熟悉的邮箱参数表单——选服务商预设（Gmail / QQ / Outlook / 自定义）→ 填 IMAP 收件与 SMTP 发件参数（Gmail 用应用专用密码、QQ 用授权码）→ 点「测试连接」分别验证收发，通过即启用。邮箱不写死，出问题随时改、随时停。

03

触发规则 · 什么单、进哪个夹子

核心屏

整套软件的大脑。左边是关键词清单（预设三条，可增可删可停），右边编辑选中规则：匹配方式、目标路径 1~N 条、附件类型、是否回信。 「原图+卡套」这一条，就配了两个路径——生产盘和备份盘。

04

自动回复 · 让客户安心

模板可编辑

文件和回信是两件事：只有必达路径全部落盘成功才回信，同一线程只回一次，避免客户收到一串重复邮件。模板中英文可切换，变量点一下就插入，右侧是真实邮件样子。

05

下载记录 · 出问题找得到件

可对账

每一封邮件、每个附件、每个目标路径都留痕。两个路径都成功就是两个绿勾；备份盘挂了就红叉 + 原因，点「重试」只补那一份，成功的路径不会重复写。

06

组件与状态 · 交给开发照着做

规范

按钮、输入框、开关、徽章、表格、Toast、空状态、托盘菜单的完整状态表，保证后续实现和设计图一致。

03.5

关键细节放大看

整屏图缩放后会看不清细节，这里把客户最在意的四处按原尺寸裁出来。

04

必须画对的四种状态

这类常驻软件的体验差距，几乎全在「不正常的时候」：正常时谁都会做，异常时要让人一眼看懂、并且敢走开。

监听中 / 已暂停

绿色呼吸点表示在收件；暂停后所有配色转为中性，顶栏常驻一条「已暂停，暂停期间到达的邮件会在恢复后补下载」。

邮箱连接失败

密码被改 / 企业禁用 IMAP / 网络抖动都会断线。概览顶部橙色横幅 + 账户卡标红，点进去改参数、点「测试连接」，不会静默停摆。

某目标路径不可用

拔了备份盘 / 网络盘掉线 / 空间不足：路径条单独标红并显示原因，其它路径继续写，绝不因为一个盘坏了就整体停摆。

部分成功 / 空状态

记录里「✔ 生产盘 / ✖ 备份盘」分开显示，可只重试失败项；规则为空时给一条引导，而不是一片空白。

05

需要客户拍板的几点

设计已按「最可能的口径」落地，下面这些点确认后只需微调，不影响整体结构。完整清单见 docs/REQUIREMENTS.md §9。

  • 关键词怎么算命中？标题「包含」即算，还是必须完全一致？现在默认：去掉空格、忽略 RE:/FWD: 前缀后精确匹配，另提供包含模式开关。
  • 没命中关键词的邮件要不要留痕？建议在记录里留一条「已忽略」，方便排查「客户说发了、但没存」。
  • 要不要一个兜底文件夹？没命中任何关键词、但带 ZIP/TIF 的邮件，也存进一个「未分类」目录，防漏件。现在默认关闭。
  • 多路径是复制还是快捷方式？设计按「复制实体文件」做（备份更可靠），会占用多份硬盘空间。
  • 一封邮件同时命中两个关键词怎么办？建议全部执行（两个文件夹都存），也可改成只执行优先级最高的一条。
  • 未来大概多少个关键词？10 / 50 / 200+，决定规则页是列表式还是加搜索优先。
  • 回信语言？英文 / 中英双语；除「已收到」是否要承诺处理时效。
  • 附件类型还要哪些？ZIP/TIF 之外是否收 JPG、PNG、PDF、PSD、AI。
  • 部署机器信息：系统版本、盘符规划（如 D: 生产 / E: 备份）、剩余空间、是否允许 7×24 不休眠。
