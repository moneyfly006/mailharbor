## 4. Token 消耗与费用（AI 路线核心）

### 4.1 口径
一个「任务会话」= 输入（读上下文/读文件）+ 输出（写代码/写文档）+ 缓存命中（重复读同一批文件）。

**实测参照**（本机 DSH 历史 84 个会话）：累计输入 1,218 万 / 输出 981 万 / **缓存读 31.6 亿**；单会话均值 输入 14.5 万 / 输出 11.7 万 / 缓存读 3,760 万。
本估算取更保守的中位量级。

### 4.2 本项目估算

| 阶段 | 会话数 | 输入 | 输出 | 缓存读 |
| --- | --- | --- | --- | --- |
| 设计期（需求+架构+6 屏+2 轮改图+文档） | 40 | 2.4M | 1.4M | 60M |
| 开发期（约 2 万行 TS/React + 调试） | 150 | 12.0M | 6.8M | 375M |
| 测试/修复/打包/文档 | 60 | 3.0M | 1.5M | 72M |
| **合计** | **250** | **17.4M** | **9.7M** | **507M** |

等效未计费总量 ≈ **5.3 亿 tokens**（含缓存重复读）。

### 4.3 按模型档位计价（2026-11 官方价）

| 模型档位 | 输入 $/M | 缓存 $/M | 输出 $/M | 本项目费用 |
| --- | --- | --- | --- | --- |
| DeepSeek V4.1 Flash 峰时 | 0.30 | 0.006 | 1.20 | **$19.8 ≈ ¥143** |
| V4.1 Flash 谷时（5 折） | 0.15 | 0.003 | 0.60 | $9.9 ≈ ¥71 |
| V4 Pro 峰时 | 1.32 | 0.044 | 3.96 | **$83.5 ≈ ¥601** |
| V4 Pro 谷时（5 折） | 0.66 | 0.022 | 1.98 | $41.7 ≈ ¥301 |
| Claude Sonnet 级（参考） | 3.0 | 0.30 | 15.0 | $349 ≈ ¥2,513 |
| Claude Opus 级（参考） | 15.0 | 1.50 | 75.0 | $1,745 ≈ ¥12,566 |

> 结论：**用 DeepSeek Flash 做完整项目，token 费用只有一百多块人民币**；即使用 V4 Pro 也才 600 元级。Token 从来不是这个项目的成本瓶颈，**人的验收与真机测试时间才是**。
> 如果不用 API 而用 IDE 内置 AI（Cursor / Claude Code / Copilot 订阅）：$20–$200/月 × 2–3 个月 ≈ **¥300–¥4,300**。

## 10. 风险与不可控成本

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 客户邮箱是 Outlook / M365 | **收不了信**（微软已停用基本认证），只能改 OAuth 或换邮箱 | **开工前确认邮箱域名**，写进合同 |
| Gmail 政策变化（App Password 收紧） | 客户需重新生成密码 | 软件内"测试连接 + 错误码指引"降级 |
| 客户电脑休眠/断网 | 漏件（可补） | 部署清单要求关睡眠；软件 resume 补扫 |
| 改需求（新增品类/字段/导出格式） | 每次 1–3 人天 | 合同写清：含 2 轮修改，超出按 800–1,500 元/人天 |
| 签名证书审核/杀软误报 | 延迟 1–2 周 | 提前买证书；上市前提交误报申诉 |
| Windows 真机验收 | 必须现场或远程 | 预留 3–5 天 + 远程协助工具 |
