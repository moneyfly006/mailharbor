隐私政策

最后更新：2026-11-24 · 适用于「邮箱资料助手（MailHarbor）」Windows 桌面应用

本政策说明「邮箱资料助手」（以下简称"本应用"）在你使用过程中如何处理数据。本应用是纯本地运行的桌面软件，开发者不运营任何收集用户数据的服务器。

1. 我们处理哪些数据

  • 邮箱账号配置：邮箱地址、IMAP/SMTP 服务器与端口、应用专用密码或授权码（加密保存在本机）；
  • 邮件内容：仅在你配置规则后，应用从你的邮箱读取邮件标题、发件人、附件元数据，并在命中规则时下载附件到本机；
  • 下载记录：邮件主题、附件文件名、目标路径、处理状态（保存在本机数据库）；
  • Gmail API 授权令牌（仅当你启用 Gmail 加速）：OAuth 刷新令牌与客户端密钥（使用操作系统级加密保存在本机）。

2. 数据如何使用

  • 在你自己的电脑上完成邮件筛选、附件下载、解压、复制到目标文件夹和自动回信；
  • 展示处理进度、失败重试与统计；
  • 不使用你的邮件内容做广告、画像或任何与上述功能无关的用途。

3. 数据存储与传输

  • 所有配置、记录、下载的附件均存放在你自己的电脑；
  • 邮件与附件只在你电脑与你的邮件服务商（如 Google、腾讯）之间传输；
  • 若你启用 Gmail 加速，附件通过 Google 官方 Gmail API（HTTPS）下载，授权令牌仅保存在本机；
  • 本应用不向开发者或任何第三方服务器上传邮件、附件、令牌或记录。

4. Google API 有限使用声明（Limited Use）

本应用使用 Google API 的方式符合 Google API 服务用户数据政策（含 Limited Use 要求）：

  • 仅申请并使用 gmail.readonly 只读权限，用于在你本机下载你指定规则命中的邮件附件；
  • 不会将 Google 用户数据用于广告、转售、数据经纪，或用于训练/改进通用 AI 模型；
  • 不会将 Google 用户数据提供给第三方，除非为提供你可见的功能所必需，或法律要求；
  • 不会以违反 Google 政策的方式读取或使用你的 Gmail 数据。

你可以随时在 Google 账号的「安全 → 第三方应用与您共享的数据」中撤销本应用的访问权限，应用内也可点「关闭加速」删除本机令牌。

5. 数据保留与删除

  • 你可以在应用内删除下载记录；删除后对应记录从本机数据库移除；
  • 下载的附件与解压文件位于你自己配置的文件夹，可自行删除；
  • 卸载应用不会自动删除你的文件夹内容；如需清除全部数据，可删除应用数据目录（%APPDATA%\邮箱资料助手）。

6. 儿童隐私

本应用面向企业/个人办公用途，不面向 13 岁以下儿童，也不会有意收集儿童数据。

7. 安全

邮箱密码/授权码与 OAuth 令牌使用操作系统提供的加密能力（Windows DPAPI / macOS Keychain）加密保存；请妥善保管你的电脑账号与系统登录密码。

8. 政策变更

如本政策发生变更，我们会更新本页面并标注「最后更新」日期。
