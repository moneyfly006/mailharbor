客户邮件附件，自动进文件夹

Windows 桌面应用 · 监听邮箱 · 按标题关键词 + 附件类型匹配 · 自动下载、解压、归档到本地多个目标路径 · 自动回信

它做什么

  • 监听 Gmail / QQ / 企业邮箱（IMAP），发现标题命中规则、且带指定类型附件（ZIP/RAR/7Z/TAR/TIF/JPG/PDF 等）的邮件；
  • 自动下载附件，复制到规则配置的多个本地文件夹（如 D:\POD\生产\手机壳）；
  • 自动解压压缩包到目标文件夹（不建子文件夹），保留原文件；
  • 自动回复客户「已收到」（模板可配置、可关闭）；
  • 大附件实时进度与速度、失败自动重试、垃圾邮件文件夹扫描、Gmail 附件 HTTP 加速（可选授权）。

运行方式

纯本地运行：邮件规则、下载记录、配置都保存在你自己的电脑上；不上传任何数据到本应用开发者的服务器。详细的数据处理方式见 隐私政策。

系统要求

系统Windows 10 / 11（x64）
网络Gmail 需要可用的网络代理；QQ / 企业邮箱一般无需代理
磁盘建议为图稿单独准备一块盘或目录
